# Insider Hunter 常见问题与经验沉淀

## 1. RPC 相关问题

### 1.1 QuickNode 免费版 413 Request Entity Too Large

**问题描述**:
使用 QuickNode 免费版调用 `eth_getLogs` 时，即使只查询 10-50 个区块也会返回 `413 Request Entity Too Large` 错误。

**根本原因**:
QuickNode 免费版对请求体大小有严格限制（约 2KB），而不是区块数量限制。`eth_getLogs` 请求包含合约地址、topics 等参数，容易超过限制。

**解决方案**:
1. **方案 A**: 将 `batch_size` 设为 1，逐块查询
   ```python
   batch_size: int = 1  # 每次只查 1 个区块
   ```
2. **方案 B**: 使用 Alchemy 免费版（限制更宽松）
3. **方案 C**: 升级 QuickNode 付费版

**代码位置**: `src/indexer/backfill.py:75`

### 2.2 唯一约束冲突

**问题描述**:
重复插入相同交易时报错 `UniqueViolation`。

**解决方案**:
使用 `ON CONFLICT DO NOTHING` 或先查询再插入：
```python
existing = await session.execute(
    select(Trade).where(
        Trade.tx_hash == tx_hash,
        Trade.log_index == log_index
    )
)
if existing.scalar_one_or_none():
    return  # 跳过重复
```

**代码位置**: `src/indexer/listener.py:85`

## 3. Polymarket API 问题

### 3.1 市场同步返回空数据

**问题描述**:
`/markets` API 返回空列表或部分数据。

**根本原因**:
Polymarket API 有分页限制，需要多次请求。

**解决方案**:
```python
async def sync_all_markets(self):
    offset = 0
    limit = 100
    while True:
        markets = await self.fetch_markets(limit=limit, offset=offset)
        if not markets:
            break
        await self.save_markets(markets)
        offset += limit
```

---

### 3.2 Token ID 映射缺失

**问题描述**:
链上交易的 `token_id` 无法匹配到市场。

**根本原因**:
1. 市场数据未同步
2. 市场已下架但交易仍在链上

**解决方案**:
1. 先运行 `sync-markets` 同步市场
2. 对于无法匹配的交易，记录日志但不中断处理

## 4. AI 分析问题

### 4.1 Claude API 速率限制

**问题描述**:
批量分析时触发 API 速率限制。

**解决方案**:
```python
import asyncio

async def analyze_batch(trades, delay=1.0):
    results = []
    for trade in trades:
        result = await analyze_single(trade)
        results.append(result)
        await asyncio.sleep(delay)  # 限速
    return results
```

### 4.2 AI 响应解析失败

**问题描述**:
Claude 返回的 JSON 格式不正确。

**解决方案**:
使用更严格的 prompt 和容错解析：
```python
import json
import re

def parse_ai_response(text):
    # 尝试提取 JSON 块
    match = re.search(r'\{.*\}', text, re.DOTALL)
    if match:
        try:
            return json.loads(match.group())
        except json.JSONDecodeError:
            pass
    # 降级处理
    return {"is_suspect": False, "confidence": 0, "reasoning": text}
```

## 5. Windows 开发环境问题

### 5.1 asyncio 事件循环问题

**问题描述**:
Windows 下运行异步代码时报 `RuntimeError: Event loop is closed`。

**解决方案**:
```python
import asyncio
import sys

if sys.platform == 'win32':
    asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())
```

---

### 5.2 路径分隔符问题

**问题描述**:
Windows 使用 `\` 作为路径分隔符，可能导致问题。

**解决方案**:
使用 `pathlib` 或 `os.path.join`：
```python
from pathlib import Path

base_dir = Path(__file__).parent
config_path = base_dir / "config" / "settings.yaml"
```

## 6. 性能优化经验

### 6.1 批量插入优化

**问题**: 逐条插入效率低

**优化方案**:
```python
from sqlalchemy.dialects.postgresql import insert

stmt = insert(Trade).values(trades_data)
stmt = stmt.on_conflict_do_nothing(index_elements=['tx_hash', 'log_index'])
await session.execute(stmt)
await session.commit()
```
