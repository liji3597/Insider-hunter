## 二、内部讨论记录

### 讨论主题：数据库设计与索引策略

**架构师**：
trades 表会是数据量最大的表，需要考虑查询性能。建议在 `market_slug`、`maker`、`timestamp` 上建立索引。

**DBA**：
同意。另外 `is_whale` 字段建议用布尔索引，配合 `timestamp` 做复合索引，加速大单查询。trader_profiles 表可以考虑物化视图，定时刷新。

**后端开发**：
胜率计算逻辑：需要关联 trades 和 markets 表，只统计 `markets.resolved = True` 的交易。建议用 SQL 聚合而不是在应用层计算。

**安全工程师**：
API 不涉及用户认证，但要注意：
1. DeepSeek API Key 必须存在环境变量，不能硬编码
2. 限制 API 请求频率，防止滥用

**最终决策**：
1. trades 表建立 `(market_slug)`, `(maker)`, `(timestamp)`, `(is_whale, timestamp)` 索引
2. 胜率计算使用 SQL 聚合，结果缓存到 trader_profiles 表
3. 所有敏感配置使用环境变量
4. API 添加简单的速率限制

## 三、数据库设计

### 3.1 表结构

#### markets 表
```sql
CREATE TABLE markets (
    id SERIAL PRIMARY KEY,
    slug VARCHAR(255) UNIQUE NOT NULL,
    condition_id VARCHAR(66) NOT NULL,
    yes_token_id VARCHAR(100) NOT NULL,
    no_token_id VARCHAR(100) NOT NULL,
    category VARCHAR(50) DEFAULT 'Politics',
    question TEXT,
    resolved BOOLEAN DEFAULT FALSE,
    resolution_outcome VARCHAR(10),  -- 'YES' / 'NO' / NULL
    active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_markets_slug ON markets(slug);
CREATE INDEX idx_markets_token_yes ON markets(yes_token_id);
CREATE INDEX idx_markets_token_no ON markets(no_token_id);
```

#### trades 表
```sql
CREATE TABLE trades (
    id SERIAL PRIMARY KEY,
    tx_hash VARCHAR(66) NOT NULL,
    log_index INTEGER NOT NULL,
    block_number BIGINT NOT NULL,
    market_slug VARCHAR(255) NOT NULL,
    maker VARCHAR(42) NOT NULL,
    taker VARCHAR(42),
    side VARCHAR(4) NOT NULL,        -- 'BUY' / 'SELL'
    outcome VARCHAR(3) NOT NULL,     -- 'YES' / 'NO'
    price DECIMAL(10, 6) NOT NULL,   -- 0.00 - 1.00
    size DECIMAL(20, 6) NOT NULL,    -- token 数量
    amount_usd DECIMAL(18, 2) NOT NULL,
    is_whale BOOLEAN DEFAULT FALSE,  -- > 10000 USD
    timestamp TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT NOW(),

    UNIQUE(tx_hash, log_index)
);

CREATE INDEX idx_trades_market ON trades(market_slug);
CREATE INDEX idx_trades_maker ON trades(maker);
CREATE INDEX idx_trades_timestamp ON trades(timestamp);
CREATE INDEX idx_trades_whale ON trades(is_whale, timestamp);
```

#### trader_profiles 表
```sql
CREATE TABLE trader_profiles (
    address VARCHAR(42) PRIMARY KEY,
    total_trades INTEGER DEFAULT 0,
    total_volume DECIMAL(20, 2) DEFAULT 0,
    win_count INTEGER DEFAULT 0,
    loss_count INTEGER DEFAULT 0,
    win_rate DECIMAL(5, 2) DEFAULT 0,  -- 0.00 - 100.00
    avg_trade_size DECIMAL(18, 2) DEFAULT 0,
    trader_type VARCHAR(20),           -- 'smart_money' / 'dumb_money' / 'normal'
    label VARCHAR(100),                -- AI 生成的标签
    last_trade_at TIMESTAMP,
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_profiles_win_rate ON trader_profiles(win_rate DESC);
CREATE INDEX idx_profiles_volume ON trader_profiles(total_volume DESC);
CREATE INDEX idx_profiles_type ON trader_profiles(trader_type);
```

#### insider_alerts 表
```sql
CREATE TABLE insider_alerts (
    id SERIAL PRIMARY KEY,
    trade_id INTEGER REFERENCES trades(id),
    market_slug VARCHAR(255) NOT NULL,
    trade_time TIMESTAMP NOT NULL,
    trade_amount DECIMAL(18, 2) NOT NULL,
    related_news TEXT,
    news_source VARCHAR(255),
    news_time TIMESTAMP,
    time_diff_minutes INTEGER,         -- 交易时间 - 新闻时间
    is_suspect BOOLEAN DEFAULT FALSE,
    confidence DECIMAL(3, 2),          -- 0.00 - 1.00
    reason TEXT,
    analyzed_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_alerts_suspect ON insider_alerts(is_suspect, analyzed_at);
CREATE INDEX idx_alerts_market ON insider_alerts(market_slug);
```

## 六、业务流程

### 6.1 链上监听流程

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│ Polygon RPC │────►│ 获取新区块    │────►│ 过滤事件     │
└─────────────┘     └──────────────┘     └──────┬──────┘
                                                │
                         OrderFilled 事件       │
                                                ▼
                                      ┌─────────────────┐
                                      │ decoder 解码     │
                                      └────────┬────────┘
                                               │
                                               ▼
                                      ┌─────────────────┐
                                      │ 匹配 market     │
                                      │ (by token_id)   │
                                      └────────┬────────┘
                                               │
                              ┌────────────────┴────────────────┐
                              │                                 │
                              ▼                                 ▼
                    ┌─────────────────┐               ┌─────────────────┐
                    │ 非政治类市场     │               │ 政治类市场       │
                    │ → 跳过          │               │ → 存储 trade     │
                    └─────────────────┘               └────────┬────────┘
                                                               │
                                                               ▼
                                                     ┌─────────────────┐
                                                     │ amount > 10000? │
                                                     └────────┬────────┘
                                                              │
                                              ┌───────────────┴───────────────┐
                                              │ YES                           │ NO
                                              ▼                               ▼
                                    ┌─────────────────┐             ┌─────────────────┐
                                    │ 标记 is_whale    │             │ 完成存储        │
                                    │ 触发 Agent 分析  │             └─────────────────┘
                                    └─────────────────┘
```

### 6.2 内幕分析流程

```
┌─────────────────┐
│ 大单交易入库     │
└────────┬────────┘
         │
         ▼

                     │
                     ▼
           ┌─────────────────┐
           │ 调用 DeepSeek   │
           └────────┬────────┘
                    │
                    ▼
           ┌─────────────────┐
           │ 解析返回 JSON    │
           │ - related_news  │
           │ - news_time     │
           │ - is_suspect    │
           │ - confidence    │
           │ - reason        │
           └────────┬────────┘
                    │
                    ▼
           ┌─────────────────┐
           │ 存储 insider_   │
           │ alerts 表       │
           └─────────────────┘
```
